# Práctica

Εφαρμογή εξάσκησης στα ισπανικά (A1–A2) για κινητό. Ανοίγει στον browser, εγκαθίσταται στην αρχική οθόνη και δουλεύει χωρίς ίντερνετ.

- `index.html`: ολόκληρη η εφαρμογή (ασκήσεις, θεωρία, ρήματα)
- `sw.js`, `manifest.webmanifest`, `icon-*.png`: εγκατάσταση και λειτουργία offline

Το λεξιλόγιο δεν περιέχεται εδώ. Φορτώνεται μία φορά από αρχείο μέσα στην εφαρμογή και μένει μόνο στη συσκευή.
